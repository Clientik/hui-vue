## Paid

- [hui-vue kit](https://huidesign.com) by [ Matt Wierzbicki](https://x.com/matsugfx) - A premium, always up-to-date UI kit for Figma - hui-vue compatible and optimized for smooth design-to-dev handoff.

## Free

- [hui-vue design system](https://www.figma.com/community/file/1203061493325953101) by [Pietro Schirano](https://twitter.com/skirano) - A design companion for hui-vue. Each component was painstakingly crafted to perfectly match the code implementation.
- [Obra hui-vue](https://www.figma.com/community/file/1514746685758799870/obra-hui-ui) by [Obra Studio](https://obra.studio/) - Carefully crafted kit designed in the philosophy of hui, tracks v4, MIT licensed
